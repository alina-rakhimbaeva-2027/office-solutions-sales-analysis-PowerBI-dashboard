## Power BI Dashboard Build Specification

This specification documents the complete Power BI dashboard workflow for the Office Solutions sales analysis.

It includes:

- Importing and preparing the `Orders` dataset from Excel
- Creating DAX columns for order size, order type, and discount bands
- Building measures for sales, profit, margins, orders, bundles, and average order value
- Designing five report pages:
  - Executive Summary
  - Product Profitability
  - Regional & Segment Performance
  - Bundles & Discount Impact
  - Sales Growth Action Plan
- Applying currency, percentage, conditional formatting, slicers, charts, tables, and dashboard footers
- Publishing the dashboard and preparing portfolio materials for GitHub
- Documenting limitations, responsible interpretation, and privacy considerations
